# User Semantics

## Goal

在当前个人 AI 投研项目中增加一个每日荐股模块：基于当天定时获取的消息、市场表现和研报，每天晚上综合评选并给出一只股票。

## Global Design Semantics

- 新模块可以做方向筛选、个股比较和最终单股推荐。
- 项目其他页面原有的客观数据与中立分析能力不需要改成荐股逻辑。

## Local Semantics

- 每天筛选五个最可能上涨的方向。
- 每个方向筛选五只股票，形成固定的 5×5 候选池。
- 读取候选股票研报，并结合市场分析与每日消息综合评判。
- 最终展示股票名称、股票代码、对应研报和研报分析。
- 每天晚上自动执行。

## User Review Focus

- 夜间任务是否按固定时间自动执行。
- 页面是否完整展示五个方向、每方向五只候选及唯一最终标的。
- 最终标的是否有真实研报链接和基于研报内容的分析。
